## What it does

`main.ts` prints exactly one line — a sick-day excuse a boss might half
believe and a coworker would laugh at, under 200 characters. The line is
built from three parts so the twist lands at the end: a believable
household emergency, an absurd escalation, and a straight-faced sign-off.

## Run it

```sh
node main.ts
```

Output (124 characters, one line):

> The plumber said don't flush anything until Thursday, so my bathroom has declared independence and I'm its ambassador today.
